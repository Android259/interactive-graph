# Абляция входов `ge_s15_prothid32_hid64_noreg` (geometric_edge, species15)

Метка `ge_s15_prothid32_hid64_noreg` (`--protein_edge_mlp`, `--bilinear_fusion`, hiddim 64,
`--protein_hiddim=32`, 14 `--protein_descriptors`, сплит `--lipid_species_coldsplit=0.15`, группа
`species15`, 5 seed'ов). Скрипт: `analysis/probes/ge_feature_ablation.py`, чекпоинты
`models/ge_s15_prothid32_hid64_noreg/groups_species15/seed*.pt`, переобучения нет. Baseline из
чекпоинтов совпал с `metrics_summary.csv` (макс. расхождение BA 0.0052, среднее 0.0010); быстрый
путь совпал с обычным (|Δp| ≤ 5.4e-7). Untouched: test BA 0.901, F1 0.860, AUC 0.953, valid BA 0.892.

Входы (18): 14 дескрипторов кармана (вещательно на узлы белка; 0 = train-среднее), `esm3` (эмбеддинг
`plm` узла; не стандартизован, среднее |x| ≈ 125), `molformer` (токены липида), `bury`, `node_x`
(`prot.x`, 3 колонки). Режимы: `zero` — ноль; `mean` — среднее по узлам train-белков / токенам train-липидов.
Shapley — выборочный (100 перестановок на seed), v(S) = метрика при ровно S оставленных входах,
замена `zero`.

## 3. Выводы

- Почти всё держат два входа: MolFormer (Shapley 0.219, обнуление −0.395 BA) и ESM3 (0.168,
  −0.324 при обнулении, −0.321 при замене средним). Вместе: BA падает до 0.50.
- Все 14 карманных дескрипторов вместе дают ΔBA 0.000 (|Δp| ≤ 0.02). Каждый из них — Shapley ≤ 0.0024,
  внутри шума (sd по seed'ам 0.001–0.005). Эта модель почти не использует дескрипторы, в отличие
  от mlp на `lipid_subclass` (там карман — основа).
- `node_x` слабый: Shapley 0.0055 ± 0.016, обнуление −0.012, замена средним −0.003.
  `bury` ≈ 0.
- Значения `zero` и `mean` для ESM3 близки (−0.324 против −0.321), то есть ESM3 нужен целиком,
  а не его масштаб.

## 4. Не проверено

- Обнуление ESM3 по частям (по размерностям) не делалось — ESM3 заменяется целиком.
- Парные эффекты между дескрипторами не интерпретируются: при MolFormer, обнулённом отдельно,
  любая пара с ним даёт −0.395 (эффект MolFormer, а не пары).
- Допущение метода: обнуление ≠ удаление признака при переобучении.
