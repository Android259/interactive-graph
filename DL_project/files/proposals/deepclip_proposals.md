# DeepCLIP: открытые предложения

> **Правило сопровождения.** Только то, что не сделано или не разобрано. Устройство
> модели и результаты — [../reference/deepclip_architecture.md](../reference/deepclip_architecture.md).
> Предложение, которое прогнали и разобрали, переезжает туда с итогом и удаляется отсюда.

Общий критерий для всех вариантов подачи белка (§1). Первый гейт провалился потому,
что белок мог одним вектором сдвинуть **весь** профиль молекулы в одну сторону, и
specificity схлопывалась в 0 или 1. Новый механизм должен не давать белку такой
возможности или хотя бы не усиливать её.

## 1. Как ещё впустить белок в DeepCLIP

| # | вариант | что меняет | статус |
|---|---|---|---|
| 1.1 | `--deepclip_protein_film` | Белок через дескрипторы кармана задаёт `γ, β` для каждого канала свёртки до LSTM: меняет, что LSTM интегрирует, может инвертировать детектор мотива. Риск: то же «один вектор на всю молекулу» | arg-файл `deepclip_start_protein_film_ep120` есть, **флага в коде нет** |
| 1.2 | `--deepclip_protein_hyperconv` | Гиперсеть по карману генерирует добавку к фильтрам свёртки: белок меняет сами детекторы мотивов | arg-файл есть, **флага нет** |
| 1.3 | `--deepclip_gate_positional` | Гейт читает и состояние LSTM в каждой позиции, а не только карман; веса центрируются по позициям молекулы, так что сдвиг «всего профиля» убран по построению | прогнано на START (5 строк в таблице), **флага в текущем коде нет**, результат не разобран |
| 1.4 | `--deepclip_gate_signed` | Веса каналов в (−1, 3) вместо (0, 2): белок может прочитать канал с обратным знаком (STARD2 и STARD10 на PE/PG хотят противоположного) | то же, что 1.3 |
| 1.5 | `--deepclip_pocket_cross_attention` | Позиции липида смотрят вниманием на реальные остатки кармана, без пулинга в один вектор. Крупное изменение, но коллапс структурно мягче | arg-файл есть, **флага нет** |
| 1.6 | `--deepclip_protein_bilinear` | Билинейное слияние вектора кармана с профилем | arg-файл есть, **флага нет** |
| 1.7 | «бедная белковая DeepCLIP» | Зеркальная conv+BiLSTM башня по остаткам кармана и позднее слияние | реализовано как `--deepclip_protein_tokens` (её вектор идёт в гейт), прогон `deepclip_start_protein_tokens_ep120` не запускался |

Arg-файлы 1.1, 1.2, 1.5, 1.6 упадут при запуске с «Unknown parameter»: их флаги не
реализованы. У 1.3 и 1.4 флаги, судя по таблице, когда-то были (прогоны есть), но в
текущем коде их нет.

## 2. Измерить то, что уже прогнано

- **Зеркальный тест гейта на GLTP.** Скопировать с кластера
  `models/deepclip/deepclip_gltp_protein_gate_ep120/` и запустить
  `analysis/probes/deepclip_mirror_pairs.py`. Это единственная метрика, которая отвечает
  на вопрос, различает ли гейт два белка на одной химии.
- **START**: `_protein_gate` против `_warm` (по 10 строк) и варианты 1.3/1.4 — разбор
  по белкам и на зеркальных тройках не сделан.
- **CRAL-TRIO** (9 белков): гейт к уже прогнанному контролю — семья, где запоминанием
  двух векторов результат уже не объяснить.

## 3. Как улучшить само измерение

- **Трёхчастный сплит химии**: обучение / validation-блок / тест-блок. Сейчас
  отложенный блок делится пополам на valid и test, то есть чекпойнт выбирается на той
  же отложенной химии, которую потом меряют. Надбавка от этого измерена ранее как
  +0.083. Такого режима в коде нет.
- **Блоки побольше**: в DeepCLIP-конфигах нет флагов балансировки, поэтому тест —
  2–22 строки. Либо включать `--balanced_proteins`, либо отчитываться только по
  измеримым семьям.
- **Танимото-близкие негативы** (`--hard_negative_mining`, механизм есть): для
  `--family_only` он испортит измерение — обогатит выборку ложными негативами.
  Использовать только с отдельной проверкой.

## 4. DeepCLIP-идеи для липидной ветки основной модели

Не для модуля DeepCLIP, а для `Lipid_encoder` основной модели (не-графовый путь
MoLFormer-токенов). Ни одна не реализована.

| # | идея | суть |
|---|---|---|
| 4.1 | `--lipid_conv_kernel=<k>` | Свёртка-сканер мотивов по токенам липида до self-attention. Свёртку нужно делать по каждому кандидату-изомеру отдельно (`to_dense_batch`), иначе она протечёт через границу кандидатов |
| 4.2 | `--lipid_sequence_model=lstm` | Явный порядок токенов, как LSTM в DeepCLIP (низкий приоритет) |
| 4.3 | вывести веса внимания наружу | Аналог «профиля связывания» DeepCLIP: какие токены липида решили ответ |
| 4.4 | маскированное предобучение липидной ветки | По образцу `structural_pretrain` для белка; задача (MSE на эмбеддинге или cross-entropy на ID токена) не выбрана |
