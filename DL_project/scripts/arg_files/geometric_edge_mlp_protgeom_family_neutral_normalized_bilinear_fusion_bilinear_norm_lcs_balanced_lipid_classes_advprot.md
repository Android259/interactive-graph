# есть белковая маргиналь, то есть он помогал угадывать, КАКОЙ это белок — ровно тому,

# адверсария. На adv-базе снятие ESM3 не проверялось ни разу, а адверсарий давит как раз
# белковую ветку — то есть ровно ту, куда ESM3 и входит. Возможны оба исхода: без ESM3
# адверсарию нечего давить и метрика не изменится, либо ESM3 был основным носителем
# идентичности и без него адверсарий перестанет стоить всей подгонки (train BA 0.884 ->
# 0.582 при снижении лосса 0.028).
#
# Зачем ещё. Если разницы нет, все последующие конфиги этой линии можно вести без ESM3:
# вдвое меньше параметров, легче прогон, и освобождается вход, который сейчас на 218:1 по
# масштабу занят ненормированным эмбеддингом (std ~289 на входе, ~218 после Linear,
# против ~1 у семи дескрипторов кармана и [0,1] у зарытости — нормировки для plm в
# обучающем пути нет нигде).
