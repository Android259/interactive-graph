# Принуждённое взаимодействие в РЕЗИДУАЛЕ кросс-внимания, на липидной оси:
# --cross_attention_forced_interaction поверх ..._advprot.
#
# Что меняется. Ровно один флаг против ..._advprot, и он отличается от соседнего
# ..._node_bilinear тем, КУДА встаёт произведение. node_bilinear добавляет его сбоку,
# отдельным каналом; здесь ForcedInteraction заменяет САМО обновление резидуала: вместо
# lip = lip + lip_outs узел обновляется произведением своего содержимого на то, что он
# вытянул у партнёра. Обходного пути мимо произведения не остаётся вовсе, тогда как при
# node_bilinear обычный резидуальный путь продолжает работать рядом.
#
# Почему именно это. Ни одно из двух направлений кросс-внимания такого произведения не
# образует: оба считают взвешенную СУММУ чужих value-векторов и прибавляют её к своему
# содержимому — это записано в докстринге самого блока. Значит на всём пути от входа до
# логита стороны перемножаются ровно один раз, в Bilinear(8,8,8) после пула, то есть уже
# над усреднёнными по всей молекуле и по всему белку векторами
# (files/geometric_edge_and_solo_next_architecture.md 8.1, 8.3).
#
# Чем подкреплено. Тот же флаг уже прогонялся под --double_coldsplit
# (..._bilinear_fusion_bilinear_norm_node_bilinear, 35 строк) и читался тогда по
# пулированной BA. Пересчёт с сохранённых вех на внутрибелковой парной метрике:
# +0.038 +- 0.022 (1.7s) к своему бейзлайну — слабее соседнего node_bilinear (+0.055 при
# 2.9s) и куда менее равномерно: выше на 5 семьях из 7, и пул держится в основном одной
# семьёй (scp2 +0.196). Прогоняется вместе с ним именно поэтому: две формы одного
# механизма, и на двойном колдсплите они разошлись (там же, 8.8). Перенос на липидную ось
# НЕ гарантирован: там вынесены и белок, и химия, здесь только химия.
#
# Оговорка, обязательная при чтении результата. У проекций ForcedInteraction есть bias
# (architecture/thematic_descriptor_head.py:96-97), поэтому "произведение" пропускает и
# каждую сторону по отдельности. Прирост, если он будет, реален, но приписывать его
# именно произведению нельзя, пока не сделана правка bias=False (раздел 3.3 того же
# файла). Этот прогон меряет модуль как он есть — ровно то же, что мерили 35 строк на
# двойном колдсплите.
#
# Ожидание, записанное ДО прогона. Если дельта переносится на липидную ось, значит узкое
# место — отсутствие попарного члена, а не ёмкость и не представление, и следующий шаг
# известен (bias=False, потом ширина взаимодействия). Если не переносится, это говорит,
# что попарный член помогает там, где неизвестен БЕЛОК, и не помогает там, где неизвестна
# только химия — что само по себе содержательный ответ про то, чего не хватает модели.
#

# files/lipid_coldsplit_architecture_direction.md).
