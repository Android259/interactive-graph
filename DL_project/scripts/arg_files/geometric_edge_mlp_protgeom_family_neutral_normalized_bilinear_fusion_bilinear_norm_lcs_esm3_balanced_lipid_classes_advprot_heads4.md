# Ширина ВЗАИМОДЕЙСТВИЯ, а не башен: 4 головы внимания вместо 8, при том же --hiddim=8.
#
# Что меняется. Ровно один флаг против ..._advprot: --HEADS=4. При --hiddim=8 это
# 4 голов по 2 измерения вместо 8 голов по ОДНОМУ. Соседние точки — 8 голов по 1 (нынешнее) и 2 головы по 4.
#
# Почему именно это. На этой линии --protein_edge_mlp, то есть свёртка идёт через
# EdgeMLPConv, у которой голов нет вовсе (conv_out_dim = hiddim, а не hiddim*HEADS,
# architecture/lipid_encoder.py и protein_encoder.py). Значит --HEADS здесь трогает
# ТОЛЬКО модули внимания: самовнимание белка, самовнимание липида и оба направления
# кросс-внимания, каждое из которых построено как MultiheadAttention(hiddim, HEADS)
# (architecture/cross_attention.py:21-22). При нынешних 8 головах на 8 измерений каждая
# голова считает совместимость произведением ДВУХ ЧИСЕЛ — механизм, на котором в
# литературе стоит всё моделирование взаимодействия, исполнен в форме, в которой он
# почти ничего не может выразить (files/geometric_edge_and_solo_next_architecture.md 8.1,
# 9.1).
#
# Почему это не «ещё раз про ёмкость». Ёмкость проверялась подъёмом --hiddim целиком
# (hid8 -> hid64): на пересчитанной внутрибелковой парной метрике -0.021 при 0.4s, то
# есть ноль (там же, 8.5). Но hid64 поднимает башни И взаимодействие сразу, а башни —
# ровно то место, где ни одна правка никогда ничего не давала. Здесь башни остаются
# ровно теми же (8 измерений на узел, те же веса по числу параметров в свёртке), а
# меняется только то, сколькими измерениями каждая голова меряет совместимость.
#
# Число параметров почти не двигается: MultiheadAttention(8, H) имеет одни и те же
# проекции при любом H, меняется только разбиение на головы. То есть это НЕ обмен
# «больше параметров — лучше метрика», а вопрос о форме механизма.
#
# Ожидание, записанное ДО прогона. Если внутрибелковая парная AUC двигается от одного
# этого флага, узкое место — взаимодействие, и тратиться дальше надо туда (произведение
# сторон до пула, независимый middim). Если не двигается ни при 4, ни у соседней
# точки — путь закрыт дешёвым прогоном, и остаётся объяснять сигнал только целью
# обучения и сэмплированием.
#
# Читать по AUC_within_protein_pairs на anionic и choline; на двух других наборах
# белковых блоков 8 и 2 (RULE в files/lipid_coldsplit_architecture_direction.md).
